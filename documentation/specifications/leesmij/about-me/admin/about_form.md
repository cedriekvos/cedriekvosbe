# Admin about-me editor

Eén beheerscherm voor de introductie bovenaan de homepage: een kop en een biotekst.

- **Eén scherm, geen lijst** — er is precies één about-me. Het document bestaat altijd, dus er is geen aanmaken,
  verwijderen of niet-gevonden.
- **Dezelfde Markdown-editor als bij een post** — niets nieuws te leren. De bio wordt letterlijk als Markdown bewaard;
  het renderen gebeurt pas op de homepage.
- **Beide velden optioneel** — de homepage verbergt het blok pas als kop én bio leeg zijn. Twee lege velden opslaan is
  dus een geldige manier om het blok te verbergen, geen fout.
- **Na opslaan terug naar de postenlijst** met "About updated.", net als bij een post. Het scherm is bereikbaar via de
  admin-header.
- **Bewust alleen tekst** — geen foto, social links of live voorbeeld. Uitbreiden kan zodra daar behoefte aan is.
