Workflow outline

checked against the repository on 2026-11-10

Where each instruction that steers an agent through this project is written down. First the sources an agent loads, in the order it loads them. Then every instruction, step by step through the pipeline, with the file that defines it and the files that repeat it.

Paths are relative to the repository root. A skill is named by its folder, so feature-specifier is .ai/skills/feature-specifier/SKILL.md.

The sources

What an agent reads, in the order it loads them. Generated files are rebuilt by Laravel Boost and are not in git.
