Domain anatomy

2026-10-24 · app/ @ 0bd1e4f

Learn one domain and you have mostly learned all of them. This page shows the repeated slice, then exactly where each module deviates from it.

The pattern

One slice, repeated five times

Every file-backed domain is built from the same parts, wired by constructor injection. App\Blog is the most complete instance, so read it as the reference: the facade is the only class the delivery layer touches, and the storage class is the only one that touches disk.
