There is no content database. Every post, page, message, bio and scratchpad note is a Markdown file on disk, read and written through a per-domain repository. The 5 bounded domains are App\About, App\Blog, App\Microblog, App\Pages, App\Scratchpad; they share one kernel, App\Markdown, and each exposes a single repository facade to the layer above.

The whole thing runs on 7 runtime packages: cedriekvos/laravel-composer-audit · laravel/framework · laravel/tinker · league/commonmark · livewire/livewire · symfony/yaml · tempest/highlight.
