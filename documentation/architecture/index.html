There is no content database. Every post, message, bio and scratchpad note is a Markdown file on disk, read and written through a per-domain repository. The 5 bounded domains are App\About, App\Blog, App\Microblog, App\Scratchpad, App\Security; they share one kernel, App\Markdown, and each exposes a single repository facade to the layer above.

The whole thing runs on 6 runtime packages: laravel/framework · laravel/tinker · league/commonmark · livewire/livewire · symfony/yaml · tempest/highlight.
