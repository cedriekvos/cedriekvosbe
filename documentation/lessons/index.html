PHP and this codebase, taught from the codebase itself. Each lesson takes a few real snippets and explains the PHP features, practices and design patterns behind them, along with what each choice costs. The lessons assume you already know PHP and spend their time on why the code is the way it is.

Lessons are added one at a time, on request, and each one builds on the ones before it.

How to read a lesson

From the codebase
Quoted verbatim from the file named above it. QA fails when the quote no longer matches that file, so a current lesson cannot show code the repository no longer has. // … marks lines left out.
Not in the codebase
An illustration: a counter-example, or the alternative the code did not choose. Never checked, and never to be copied as house style.
Highlighted lines
The part of a snippet the text around it is talking about.
Check yourself
Every lesson ends with questions and collapsed answers. Answer first, then open. Recalling an answer teaches more than rereading one.
Current
The lesson describes the code as it is today. When the code changes and the lesson still teaches the same thing, the lesson is updated along with it.
No longer in the codebase
The code changed so much that updating the lesson would turn it into a different lesson. It stays as written and names the commit its snippets were true at, so git show <commit>:<path> still shows the original.

The check is php documentation/tools/check-lessons.php, and it runs as part of composer qa.
