# Admin microblog list

Hetzelfde patroon als de postenlijst: alle berichten, de nieuwste eerst, met bewerken en verwijderen.

- **Geen `draft`-label** — berichten kennen geen concepten.
- **Datum én tijd** (`01/05/2026 14:32`) — er verschijnen vaak meerdere berichten per dag.
- **Verwijderen is direct en definitief** — er is geen prullenbak.
- **Een lege lijst** toont "Nog geen berichten." in plaats van een leeg scherm.
