# Message links in de admin

Wat een link wordt, staat in `leesmij/microblog/frontend/message_links.md`. Dit document gaat over waar links in de
admin wel en niet verschijnen.

- **De lijst toont links** — zo controleer je na het plaatsen of de link werkt, zonder naar de homepage te gaan. Wat je
  in de lijst ziet, is wat de bezoeker ziet.
- **Het invoerveld niet** — wie de bron bewerkt, moet de ruwe tekst zien.
- **De limiet van 280 tekens telt de volledige URL** — URL's anders tellen (zoals Twitter met t.co) maakt de limiet
  onvoorspelbaar en de teller oneerlijk. Een scenario legt dit vast, zodat een wijziging een bewuste keuze moet zijn.
