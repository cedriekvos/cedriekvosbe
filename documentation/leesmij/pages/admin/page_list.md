# Admin page list

Dit overzicht is de pagina-tegenhanger van [[post_list]] en volgt dezelfde regels: alle pagina's zijn zichtbaar,
inclusief concepten, met een `draft`-label voor wat nog niet live staat. Een redacteur moet werk-in-uitvoering net zo
goed kunnen terugvinden als bij posts.

Er is geen datumkolom, simpelweg omdat een pagina geen datum heeft om te tonen — dit overzicht is verder identiek aan
het postoverzicht: verwijderen vraagt een bevestiging voordat het bestand van schijf verdwijnt, en na afloop verschijnt
een korte bevestigingsboodschap. Ook hier kiezen we voorlopig voor één enkele lijst zonder paginering of zoekfunctie,
om dezelfde reden als bij posts: bij het huidige, kleine aantal pagina's voegt dat niets toe.
