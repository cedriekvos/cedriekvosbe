# Header GitHub link

Een link naar mijn GitHub-profiel (github.com/cedriekvos) in de header van elke publieke pagina, zodat bezoekers mijn
code kunnen bekijken.

- **Alleen de publieke header** — de admin is een werkplek; daar is de link ruis.
- **Nieuw tabblad met `rel="noopener noreferrer"`** — de bezoeker blijft op de site, en de externe pagina krijgt geen
  toegang tot `window.opener`.
- **Alleen een icoon, met het label "GitHub"** — dat houdt de header compact; het label maakt de link herkenbaar voor
  schermlezers.
- **Puur zwart in licht, puur wit in donker** — dezelfde kleuren als het LinkedIn-logo ernaast
  ([[header_linkedin_link]]), zodat de twee profiellogo's bij elkaar passen en in beide thema's goed zichtbaar zijn. De
  tekstkleur van de site en de theme-toggle blijven gedempt.
