# Voorbeeldweergave van een post

Een redacteur wil een post zien zoals een bezoeker hem ziet, vóór het publiceren.

- **Knop in de editor, opent een nieuw tabblad** — de editor en niet-opgeslagen werk blijven staan. Het overzicht
  krijgt geen knop.
- **Eigen URL onder `/admin`, achter de login** — de openbare URL van een concept blijft een 404, dus er lekt niets.
- **Ook voor gepubliceerde posts** — één knop, geen uitzonderingen.
- **Toont wat opgeslagen is** — een live voorbeeld van niet-opgeslagen invoer kost meer dan het oplevert. Een nieuwe,
  nog niet opgeslagen post heeft daarom geen knop.
- **Duidelijk een voorbeeld** — een melding voorkomt verwarring met de echte pagina. Slugformaat en HTML-escaping
  volgen de openbare weergave ([[post_detail]]).
