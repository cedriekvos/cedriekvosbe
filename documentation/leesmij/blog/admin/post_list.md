# Admin post list

Het beheeroverzicht toont álle posts, ook concepten, zodat een redacteur werk-in-uitvoering terugvindt. Concepten
krijgen een `draft`-label.

- **Verwijderen vraagt bevestiging** — het bestand verdwijnt definitief; daarna volgt "Post [slug] deleted.".
- **Eén lijst, geen paginering of zoekfunctie** — volstaat bij het huidige aantal posts.
- **Datum als dag/maand/jaar** — dezelfde notatie als op de publieke site. Het datumveld in het formulier houdt zijn
  technische invoerformaat.
