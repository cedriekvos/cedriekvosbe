# Homepage featured post badge

De "Uitgelicht"-badge is een redactionele keuze: een post krijgt hem alleen als de redacteur hem in [[post_form]] als
featured markeert.

- **Handmatig, niet automatisch** — wat uitlichten waard is, valt niet samen met de datum; een ouder, tijdloos stuk kan
  relevanter zijn. De badge kan dus op elke positie in de lijst staan.
- **Meerdere tegelijk mag** — er is geen reden om er één af te dwingen.
- **Geen terugval** — is niets gemarkeerd, dan is er geen badge. Terugvallen op de nieuwste post zou de badge weer
  betekenisloos maken.
- Een featured concept blijft onzichtbaar tot het gepubliceerd is ([[homepage_posts_list]]).
