# Admin scratchpad

Eén plek in de admin voor losse notities, zoals ideeën of to-do's, die nooit worden gepubliceerd.

- **Eén document, geen lijst** — zoals de about-me editor ([[about_form]]): openen, bewerken, opslaan.
- **Gedeeld, niet per redacteur** — nergens in de applicatie is content per gebruiker gescheiden, en een kleine groep
  redacteuren kan één informeel document delen.
- **Dezelfde Markdown-editor als bij een post** — vertrouwd, en er is niets extra's te onderhouden. De inhoud wordt
  letterlijk bewaard.
- **Leeg mag** — wie de notities heeft verwerkt, moet ze kunnen leegmaken.
- **Na opslaan terug naar de postenlijst** met "Scratchpad updated.", zoals bij de andere editors. Het scherm is
  bereikbaar via de admin-header.
- **Geen geschiedenis of meerdere notities** — één document dat bij elke opslag wordt overschreven.
